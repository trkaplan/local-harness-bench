 # todo
 
-A small CLI todo manager backed by a JSON file. `python -m todo.cli --file t.json add "x"`.
+A small CLI todo manager backed by SQLite by default (`~/.todo.db`); a JSON file
+backend is still available. The backend is chosen by file extension: `.json` uses
+JSON, anything else uses SQLite.
+
+```
+python -m todo.cli add "x"                    # uses ~/.todo.db (override with --file or TODO_FILE)
+python -m todo.cli --file t.json add "x"      # JSON backend
+python -m todo.cli rename 1 "new title"       # rename task #1
+python -m todo.cli migrate t.json t.db        # copy tasks between backends (either direction)
+```
+
+`migrate` fails with `destination not empty` if the target already has tasks.
+
